# 实施计划（分批实现）

> 依据：[成熟路线方案.md](成熟路线方案.md)。每批完成后先验证再进入下一批，并在本文件勾选。

## 一、技术选型

| 部分     | 选型                                                                                 | 说明                                                         |
| -------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------------ |
| 后端     | Node.js + TypeScript + Express                                                       | 与现有项目一致                                               |
| 数据库   | SQLite（better-sqlite3）                                                             | 全部历史约 3,600 期，数据量小                                |
| 定时任务 | 自写简易调度器（按北京时间）                                                         | node-cron 3 依赖有漏洞、修复版需 Node 20，需求简单故自行实现 |
| 随机数   | 可设种子的伪随机数生成器                                                             | 推荐与回测结果可复现                                         |
| 统计计算 | 自行实现（模拟检验、BH 校正、最小二乘回归）                                          | 用到的方法少，不引入大型统计库                               |
| 测试     | vitest                                                                               | 只覆盖号码校验、奖级判定、回测防泄漏三处                     |
| 前端     | 原生微信小程序 + TypeScript + TDesign                                                |                                                              |
| 图表     | 冷热格、遗漏表、频次条形图用 WXML + WXSS 画；走势和回测曲线用 ECharts 定制版，放分包 |                                                              |

```
ssq-predictor/

    src/

      collector/   采集、解析、校验
```

### 第 6 批：回测框架与随机基线

- [X] 常规六奖级与福运奖最高奖级判定；每注 2 元，按各期公告金额作税前回放。全区间命中数与可核算子集命中数分别记录。
- [X] 收益边界：整期审计原文；含加奖/派奖、额外派奖字段、缺失/为零浮动奖金等暂停核算，不因某次是否命中而挑选收益样本。单注公告金额包含加奖时不擅自扣除或套用。
- [ ] 正式全收益 ROI：历史活动资格尚未核实，暂为 null；已核算子集 ROI 只是固定历史公告金额、税前的描述性回放，不计税收/兑奖，也不模拟额外投注对浮动奖的稀释。
- [X] 滚动回测：预测只收到目标期号与严格早于目标的号码历史；不传销售/奖金/原始记录；历史递归冻结，返回预测先复制/冻结再读目标开奖号评分，记录预测内容哈希。
- [X] M0 随机基线：公平不放回抽 6 红、均匀抽 1 蓝，多注仅拒绝整注重复；每次重复独立创建预测器并派生种子，保留所有重复，不择优挑种子。
- [X] 指标：红球边际二元 log loss/Brier 按 33 项平均，蓝球分类 log loss 与 16 类 Brier 求和；平均红命中、蓝命中率、奖级、已核算收益、全核算时的净值回撤。概率与有限推荐票的号码频率严格区分。
- [X] 随机重复分布：均值/中位数/极值/95%结果分位区间；命中与评分报告近似 MC 均值区间，奖金重尾不报告正态均值区间。首重复相对其余 M0 的双侧加一尾概率只用于框架校准，不是策略优越性 p 值；非 M0 比较在第 7 批实现。
- [X] 回测登记：每次执行记录策略/版本/参数/种子/注数/起止期、所有重复汇总、数据指纹、报告路径及成功/失败状态；成功后不可经仓储接口覆盖。输出使用独占新文件，避免覆盖旧报告。
- [X] 前瞻锁定：迁移 v3 新增不可改写的政策登记，2026125 起本批一律禁止读取用于回测/运行评估；尚未登记而该段数据已入库时拒绝事后声称未触碰。2023 年起历史仅作探索回放。
- [ ] 最终模型定稿前另行预登记前瞻评估长度、候选策略/参数搜索登记方案与唯一解锁执行流程；本批不解锁、不提前查看前瞻结果。

- **验收（2026-10-31）**：类型检查/构建通过，全量单元测试 58 项（原解析 21、奖级 22、回测 15）通过，基础 27 项与研究 28 项回归通过；`verify:backtest` 独立验收 102.6 万票的命中均值、概率评分及 17,721,088 组合空间的奖级计数。

### 第 7 批：基础模型与组合生成

- [X] M1 平滑频次、M2 时间衰减、M3 冷热遗漏（只作对照）；固定窗口 300、100 期等价公平先验、M2 半衰期 100、M3 遗漏指数 0.25（倍率封顶 3），不搜索最优参数。
- [X] M1 红权重=窗口出现次数+100×6/33，蓝权重=出现次数+100/16；M2 使用按观测历史期距衰减的出现次数，先验不衰减；M3 在 M1 权重上乘有界遗漏系数，窗口未出现仅是遗漏下界，不视为“欠开奖”。
- [X] 精确红球分布：固定 6 元子集的概率正比于所含权重乘积；前/后缀基本对称多项式 DP 计算各号包含边际并按条件概率抽样。不将归一化权重×6误当包含概率，不冒称顺序加权抽球分布。
- [X] 组合生成：票内不放回、多注整票去重、可限制任意两注红重叠、记录可复现随机种子；无法满足约束时明确失败，不静默松绑。回测比较统一最大红重叠=6，不加结构过滤。
- [X] 概率口径：评分对应单注基础分布；去重和重叠拒绝后，后续注的条件边际会改变，报告明确区分，不宣称约束后仍是原基础边际。
- [X] M0/M1/M2/M3 同起止期、同注数成本、同重复种子回测；全部四组配置在执行前登记，保留失败记录与所有重复；确定性分布按不可变历史缓存，随机票不缓存。
- [X] 比较报告：四项评分的“基线损失－模型损失”逐期配对差，正数为改善；2,000 次环形移动块 bootstrap、预设块长 10、近似 95% 区间、中心化双侧 p 值，3 模型×4 指标共 12 项统一 Holm 校正。不是精确随机化检验，不将随机重复当作独立历史评分样本。
