## 1. 产品与视觉方向

- 定位：**双色球数据观察 · 透明随机推荐与历史研究**，不使用“智能预测”“高胜率”“稳赚”等措辞。
- 基调：浅灰背景、白色卡片、深色文字；红色只用于红球与必要的产品强调，蓝色用于蓝球与研究入口，避免赌场式大面积红金、中奖烟花、倒计时催促。
- 第一屏先说明 M0 是公平随机基线，然后展示期号、状态与固化号码；不加推荐评分、热度收益标签或“再换一组”。
- 不提供支付、代购、投注倍数、购彩跳转或鼓励加注的交互；“复制号码”仅复制已有固化号码及期号，不能触发重新生成。
- 时间一律标明北京时间。20:00称“保守生成截止”，不是官方停售时间；生成时间与哈希不描述为第三方可信存证。

### 号码与命中规范

1. 红球六个升序、蓝球与红区间隔16rpx；统一显示两位数01–33/01–16。
2. 每一注有“第N注”或可访问标签；读屏内容为“红球02、12……蓝球11”，不只朗读色块。
3. 命中时使用描边、勾选符号及“命中3红 / 蓝未中”文字。未命中仍可读，不使用过淡透明度。
4. 选号体检候选号未选中为白底带编号描边，选中为实体球 + 勾选标识；计数同时显示“红球6/6，蓝球1/1”。

## 5. 八页线框、字段与交互

### P01 推荐首页

线框顺序：原生导航 → 研究定位提示 → 下期期号/日期/状态 → M0说明 → 已固化号码（默认5注） → 查看核验/策略入口 → 折叠审计信息 → 最新开奖卡 → 常驻短免责 → Tab。

- 读取 `GET /api/recommendations/next` 和 `GET /api/draws/latest`；最新开奖卡进入P02详情。前端不携带管理密钥，也不调用管理生成接口。
- `not_generated`：显示“服务器尚未生成”，不画随机假票；刷新仅重新GET。
- `available`：显示原件与生成时间，可复制已有号码；不显示生成/换号按钮。
- `closed`：已有原件仍显示，标“已过保守生成截止”；无原件则显示未生成，不补造。
- `awaiting_draw`：根据reason显示源期开奖未完成或目标开奖待同步，不误写成已经中/未中。
- `sourceLatestIssue`、`generationDeadline`、`generatedAt`、`contentHash`分属源数据、生成政策、实际生成、内容审计，不混为官方开奖状态。

### P02 历史开奖及单期详情

线框：导航 → 期号输入框（精确查询） → 期号/日期 + 号码行列表 → 加载更多；点记录进入详情：号码 → 结构小卡 → 销售额/奖池 → 奖级表 → 数据缺失提示 → 来源/免责。

- 列表 `GET /api/draws?limit=20&beforeIssue=...`，接口返回 `nextBeforeIssue` 作为排除式游标；不存在的精确期号404提示“尚未收录该期”。不得假设支持日期范围或服务器年份筛选。
- 精确查询/详情 `GET /api/draws/:issue`；结构可以用详情号码做纯函数展示，或在该期 `asOfIssue` 特征报告里取对应行；未做官方核实不展示开奖球顺序。
- `prizeGrades`按编号显示单注金额/中奖注数；`null`显示待公布。`isPrizeDetailComplete`只代表常规奖级中奖注数齐全，**不意味着派奖收益规则已核实**。
- 现有公共开奖详情没有福运奖原始字段，不把`prizegrades`第7项占位误当福运奖；后续如需完整特别奖表，先补正式公共字段。

### P03 号码分析

线框：导航 → 红/蓝切换 → 全部可用/近30/100/300期 → 实际样本/截止提示 → 频次冷热网格 → 点号码的详情抽屉 → 遗漏表 → 和值/奇偶/分区走势入口 → 回测/选号体检入口 → 风险短句。

- `GET /api/statistics?window=100` 或 `GET /api/features?window=100&asOfIssue=...`，**两个端点当前都返回完整基础报告**，同筛选下复用请求，不重复加载。
- 数量、实际首尾期用 `sampleDrawCount/firstIssue/lastIssue`，统计上界用 `requestedAsOfIssue`；警告来自 `warnings`。
- 冷热依据频次分位数，用“冷/常/热”字样；并列不强行分级。遗漏按未出现期数，均值只用两次出现之间完整间隔。
- 走势数据来自升序 `features`；跨缺期的重号/振幅null断线，不补零。长历史默认仅绘可见最近100点，可展开分页/缩放，不截取后冒称全量。
- 网格/遗漏/频次条用view，复杂走势用定制ECharts；红频次与蓝频次分图，避免基数不同直接比较。

### P04 策略说明

线框：导航 → 当前线上策略“M0” → 理论概率 → 模型目录 → 点击展开原理/参数/局限 → 回测入口 → 风险提示。

- M0“当前透明随机基线”；M1/M2“历史探索对照”；M3“遗漏反例对照”；M4/M5“暂不准入”。不存在“选择策略立即推荐”。
- 原理、固定参数与限制用版本化本地说明配置；当前推荐版本可从P01/推荐详情取得，既有实验参数不能冒充当前线上参数。
- 第7批报告显示三个固定对照四项概率评分差于M0，不支持宣传“更聪明、更高命中”；完整比较尚无公开端点，仅能作为已注明日期、范围、来源的静态研究说明，不能标“实时报告”。

### P05 回测看板

线框：导航 → 探索性历史提示 → 已保存运行选择（名称/版本/起止/注数） → 红命中均值/蓝命中率 → 理论参考 → loss/Brier定义 → 随机结果区间 → 收益暂停说明 → 方法与局限。

- `GET /api/backtests?limit=20&beforeId=...`；只读已保存汇总，不启动CPU回测。
- 列表包含 running/succeeded/failed，不删除失败任务；running显示进行中、failed显示失败状态而非内部异常；`summary=null`不画指标。
- 跨模型比较须核实**相同数据指纹、同定义、同时间段/注数/重复数**；当前公开接口未返回重复次数与完整策略参数，首版只允许切换查看单个运行，不做跨模型排行榜，不猜测重复次数或提供“参数复现”按钮。
- `distributions.*.outcomeInterval95`称“整段随机重复结果区间”；`monteCarloMeanInterval95`称“随机重复均值MC区间”，不称“历史模型优势区间”。红边际/蓝分类loss不同口径，不跨颜色排列强弱。
- 正式ROI显示“暂不提供”；审计暂停期数从 `payoutAudit.withheldIssues.length` 获取。不能从子集奖金均值臆造全收益曲线。
- **接口缺口**：逐期命中/收益曲线、跨模型配对区间及Holm p值未通过此接口公开。首版不画假曲线、不从端口读服务器报告文件；需要时先设计并补公开只读对比端点。

### P06 推荐核验

线框：导航 → 推荐档案列表（期号/生成时间） → 点击详情 → 固化号码 → 目标开奖/当前核验 → 逐注命中/奖级 → 核验口径/收益暂停 → 审计信息 → 历史修正版本。

- `GET /api/recommendations?limit=20&beforeId=...` → `GET /api/recommendations/:id/verification`；为避免列表N+1请求，不在列表假造核验摘要，进入详情才请求核验。
- 当前接口核验结果不带目标开奖号码；详情通过 `GET /api/draws/:issue`补齐。404表示未入库，不自动判未中。球命中标记按当前匹配核验的outcomes及目标开奖号做展示。
- `latest=null`：目标未开奖/未同步时显示待开奖；有目标开奖但尚无匹配核验显示“当前版本待核验”。用“latest=null”不能推断未中奖。
- `latest`为与当前开奖指纹匹配的结果，`versions`只是新增版本排序。A→B→A修正时，不能再次用`versions[0]`覆盖`latest`。
- 展示generatedAt及完整可复制hash；核验时间取verifiedAt。收益仅在审计通过且值非null时标“税前公告金额回放”，同时声明非实际兑奖收益。

### P07 选号体检

线框：导航 → 红6/蓝1规则提示 → 红33格选择 → 蓝16格选择 → 选择计数 → 单注预览 → “查看结构” → 和值/跨度/奇偶/分区/AC → 理论概率与局限。

- `POST /api/tickets/check`，body仅 `{redBalls:[...],blueBall:...}`；红恰6个/蓝恰1个且不重复，合法后启用按钮，不接受倍投、票数或服务端随机种子。
- 提交中禁重复点击，结果在号码再次编辑后失效；非法输入提示具体位置，API失败保留选择；号码只在本地选择，不上传身份、不持久化选号历史。
- 主按钮称“查看结构”，不称“测胜率/优化推荐”。概率始终1/17,721,088；**不显示撞号热度、评分、优选/劣选标签**，当前接口没有这些能力。
- 重置先清空本地选择；不请求管理生成接口。静态设计预览中的球与按钮不可操作，不能误当已实现产品。

### P08 关于与免责

线框：导航 → 产品定位/版本 → 数据来源与范围 → 透明记录说明 → 策略/核验入口 → 风险与未成年人提示 → 隐私说明 → 合规状态 → API/网络状态（可选）。

- 数据来源中国福彩网，当前仅2013年起可用历史；动态范围可复用最新开奖与统计报告，历史总数未查询时不凭空估计。
- 声明“仅供数据研究与娱乐，不构成购彩建议，不承诺中奖或收益；不提供代购、支付或资金交易。未成年人不得购彩及兑奖”。
- “小程序类目、主体及上线形态仍待核实”，不宣称已审核通过/官方认证；不使用未经授权的官方logo。
- 隐私说明按实际行为编写：首版不登录、不取位置/通讯录、不读系统剪贴板，复制需用户主动；后端有IP限流处理，生产访问日志策略/保存期限上线前补全，不宣称绝对零采集。
- 只在用户主动点击时打开官方来源说明，不引导购彩；故障说明不显示后台管理密钥、内网路径或SQL。

## 6. 通用状态与请求约定

| 场景 | 展示与操作 |
| --- | --- |
| 首次加载 | 标题保留，内容骨架，不用0或假票占位 |
| 空数据 | 缺少历史/尚未生成/尚无核验分别说明；提供只读刷新入口 |
| 网络失败 | “未能取得最新数据”，手动重试；已有数据明确上次取得时间，禁止伪装当前状态 |
| 429 | “请求频繁，请稍后再试”；尊重Retry-After，无循环立即重试 |
| 历史缺期/样本不足 | 展示后端warnings，不能只打印console |
| 日期/数据过旧 | 显示“目标开奖待同步”，保留原件，不本地递推补造下一期 |
| 管理操作 | 不出现在公众小程序；没有客户端管理密钥/管理入口 |

成功解析 `{data,...}`，错误解析 `{error:{code,message}}`；使用独立API客户端配置合法HTTPS服务域名。不直接请求中国福彩网、不在公共小程序持久化管理token。刷新仅由用户/页面生命周期触发，不做秒级轮询或自动后台跑回测。

## 7. 文案与图表红线

- 常驻短句：“随机推荐不提高单注中奖概率。仅供研究与娱乐。”完整细则在关于页及审计折叠区。
- 禁止：中奖概率随冷热变化、命中率累计保证、连续失败加倍、历史高收益作为主广告、未核验视作未中奖、无数据补零、假统计曲线。
- M0红命中1.091/蓝6.25%是理论均值，不是这5注的“预测准确率”；第7批实测数字仅当明确样本和时点时作研究展示。
- 简单数值图配单位/实际样本/图例；95%结果分位区间不叫获利区间。曲线缺失不画，看板首版用汇总卡与表格。
